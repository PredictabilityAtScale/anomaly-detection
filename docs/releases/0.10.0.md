# Anomalyzer 0.10.0

Adds opt-in calendar and rate evidence for analysts and agents working with
sparse customer data. The package uses the existing dependencies.

- Schema 1.1 can match earlier periods in a declared local timezone. Calibrated
  fallback can use a broader supported period while a narrower reference learns.
  Reports include peer dates, calibration support, and reasons for abstaining.
- Optional calendar expected ranges use earlier prediction errors. Callers can
  inspect the bounds, support and calibration cutoff alongside detector evidence.
- `rate-v1` compares integer successes and trials with a two-sided Fisher exact
  test and Wilson intervals. Bounded chronological replay pools exposure across
  trailing windows and reports missing or zero exposure explicitly.
- The read-only MCP rate tools return contextual summaries and session IDs for
  drilling into comparisons and source counts. Agents can combine that evidence
  with operational context under the caller's alert policy.

UsageTap can adopt the new APIs for opt-in investigation and historical replay
after the immutable artifact passes publication verification. Keep calendar
fallback and rate replay under evaluation before using either for recurring
alerts. Calendar fallback scored more of the hourly replay and found more
incidents, with more total false runs. The five-minute rate replay eliminated
false runs on its independent-noise controls and missed three sparse incidents.
Clustered trials require particular care, and the MCP summary can surface older
findings ahead of recent unconfirmed comparisons.
