# 0.7.0 — native historical anomaly evidence

Stable version: **0.7.0**. Release assets are built from the merged tagged
revision and verified on Python 3.11–3.13, including installed wheel/sdist
regressions and an offline Linux x86_64/Python 3.12 Lambda consumer. Published
assets carry their exact source revision, checksums and pinned runtime locks.
Released v0.6.0 and prior assets are preserved. This release does not deploy UsageTap.

Opt-in `ForecastSettings.historical_anomalies` returns typed
`historical-anomalies-v1` evidence from the historical analysis already performed
by `forecast_series`: original-position signed references, residuals, nullable
scores, point triggers, maturity/calibration support, first-detection pattern
snapshots, model operations and provenance. No second analysis or new runtime
dependency. Existing forecast arrays and analysis/distribution/Guard behavior
are retained.

See the [API specification](../historical-anomalies.md) and
[UsageTap migration](../usagetap-forecast-migration.md). Adoption requires a
verified immutable 0.7.0 artifact, updated exact engine pins and an explicit
consumer evidence extension. The exploratory detector stays unavailable until
the consumer verifies and adopts those assets. Consumer materiality/severity and
saved notifications remain caller policy.
