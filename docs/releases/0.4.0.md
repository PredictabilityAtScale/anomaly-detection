# Anomalyzer 0.4.0: numeric and categorical population changes

This additive release introduces `distribution-v1`; existing schema-1.0/1.1
time-series requests, recipes and case policy retain their behavior.

- `compare_distributions` compares explicit disjoint populations with source IDs,
  support, effect sizes, inference assumptions, statistical/practical gates and
  reference fingerprints. Unknowns and incomplete observations remain inspectable.
- Numeric `ks_tie_exact` counts exact conditional label permutations over whole
  tied groups. Zero-heavy mixtures and mean-preserving shape changes need no
  normality assumption, histogram or outlier deletion.
- Categorical `jensen_shannon_permutation` assesses the whole composition, using
  exact small-population permutations or reproducible plus-one Monte Carlo
  probabilities. Category shares explain the finding. Individual quantity-weighted
  reports are permuted as whole events; aggregate-only consumed units produce
  descriptive effects, never invented independent sample counts.
- `monitor_distributions` replays a frozen reference and bounded recent windows
  with a predeclared finite testing family. All planned looks/window sizes share
  a Bonferroni budget. Unknown current positions break windows, unfinished
  suffixes stay excluded, and first detection retains index/ID/time/window.
- Python exports, two JSON CLI commands, two read-only MCP tools, method discovery
  and four generated schemas expose the same core. CLI and MCP now report the
  authoritative package version. README chapters 25–26 add real-engine synthetic
  graphics and controls. A [UsageTap handoff](../distribution-detection.md)
  describes measurement choices and caller responsibilities.

The new MCP tools return full population results directly, outside the old
time-series session cache. Clients enumerating an exact tool list must accept
`compare_distributions` and `monitor_distributions`. The CLI's existing `analyze`
command retains its time-series contract; use `compare-distributions` and
`monitor-distributions` for the additive requests.

Inference requires an explicit caller assertion of independent exchangeability
under the null. Clustered calls, retries, serial dependence, traffic-mix changes
and informative missingness are not repaired automatically. Statistical evidence
is not incident confidence. Finite testing families must not be restarted for a
free budget; callers own persistent reference/family state, as-of snapshots,
finding deduplication, scheduling and business policy. Permutation resolution and
runtime failures are explicit non-triggering statuses. No automatic regime reset,
block permutation, persistent streaming service or alert delivery is added.

The package remains alpha, standard-library numerical code plus its existing
validation dependencies, supporting Python 3.11–3.13. Synthetic tests establish
implemented behavior; qualify detection delay, false findings and compute cost on
representative chronological UsageTap traffic before adopting operational policy.
This source release does not change or deploy UsageTap. Follow the
[release guide](README.md) to build, verify and publish immutable artifacts.
