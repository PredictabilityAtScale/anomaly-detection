# 0.6.0 — public forecasting

Add `forecast_series`, public typed `Forecast*` models and independent
`forecast-v1` request/result schemas. Forecast fixed-fit scenarios with signed
values or an explicit lower bound, distinct complete/partial/missing statuses,
calendar cadence checks, original-coordinate metadata and explicit unavailable
reasons. Expose current fitted trend/seasonal components separately from frozen
causal historical expectations and calibrated anomaly maturity. No uncertainty
intervals or production accuracy guarantees are added.

Include anonymous chronological evaluations, forecast smoke tests, a
`usage-forecast-v1` compatibility bridge and the
[exact UsageTap migration](../usagetap-forecast-migration.md). Existing analyze,
distribution and Guard behavior is unchanged. Robust/include sensitivity and
regime-change weaknesses are documented; Current remains UsageTap's default.

Release assets bind a reviewed source commit to the tested wheel and sdist,
supported-Python checks, offline Lambda validation and pinned runtime dependency
hashes. The release is distributed through immutable GitHub Release assets.
No UsageTap branch, deployment or release is changed by this upstream release.
