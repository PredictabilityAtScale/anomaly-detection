Start with the story map to explore eight deliverable lanes. Open a capability to inspect its behavior, acceptance criteria, supporting evidence, and limits.

  3. Incomplete-period monitoring: compare finalized data while periods remain open.
  4. Related-metric analysis: inspect declared ratios, gaps, and delayed responses.
  5. Evidence and review policy: judge support and review eligibility.
  6. Python integration: embed validated analysis in an application.
  7. Anomaly detection Skill: get a guided explanation and optional chart.
  8. Read-only MCP server: let an agent inspect local findings and evidence.

Each capability has one primary lane; dependencies show shared prerequisites. These lanes describe current deliverables, not scheduled releases. The caller owns notification delivery and operational actions.

Coverage reflects saved capability reviews. It does not measure detection accuracy on real-world data.
