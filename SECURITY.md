# Security policy

## Supported versions

Security fixes are applied to the latest version on the default branch while
the project is in alpha.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, sensitive data, or credentials.

Include the affected version or commit, a minimal reproduction, the potential
impact, and any suggested mitigation. You should receive an acknowledgement
within seven days.

Anomalyzer processes local input. Avoid sharing production or customer data in
reports; use a minimized synthetic example whenever possible.
